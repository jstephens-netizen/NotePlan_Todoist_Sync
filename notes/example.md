# Example NotePlan Note

This is an example note showing the task format supported by the sync tool.

## Tasks
- [ ] Buy groceries #errands >2025-03-01
- [ ] Review pull request #dev #code-review !!
- [ ] Schedule dentist appointment #health >tomorrow !
- [x] Send weekly report #work

## Notes
Any non-task content in your notes is ignored by the sync tool.
You can organize your notes however you like — only lines matching
the `- [ ]` / `- [x]` pattern are parsed as tasks.
